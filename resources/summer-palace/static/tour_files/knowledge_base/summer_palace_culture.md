# 颐和园历史建筑知识

## 仁寿殿

仁寿殿位于东宫门内，是颐和园东部宫廷区的重要建筑。其功能以处理政务、接见活动为主，建筑布局端庄严整。游览时可重点观察殿前陈设、院落尺度以及宫廷区与后方山水园林之间的空间转换。

## 长廊

长廊沿昆明湖北岸展开，把多处园林建筑和湖山景观连接起来。梁枋绘画题材丰富，包含山水、花鸟、人物故事等内容。长廊既具有遮阳避雨的实用功能，也是颐和园“移步换景”游览体验的重要载体。

## 佛香阁与万寿山

佛香阁位于万寿山前山中部，是颐和园最醒目的标志性建筑之一。建筑借助山势形成层层抬升的中轴景观，从湖面、长廊等位置都能形成清晰对景。登临区域视野开阔，适合观察昆明湖与园林总体格局。
