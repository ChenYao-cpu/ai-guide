# 颐和园景区总览与游览服务知识

## 景区定位

颐和园位于北京市海淀区，是以万寿山、昆明湖为主体的大型皇家园林。园林将北方皇家建筑的秩序感与江南山水园林的借景、对景手法结合起来，适合开展历史文化、古建筑、园林艺术、湖景摄影和亲子研学等主题游览。

## 推荐游览方式

- 经典文化线：东宫门—仁寿殿—长廊—佛香阁，约 100 分钟。
- 湖畔风光线：长廊—昆明湖—十七孔桥，约 90 分钟。
- 亲子轻松线：苏州街—长廊—昆明湖，约 80 分钟。

景区面积较大，游客应根据体力和停留时间选择路线。湖边和山路存在台阶、坡道，雨雪天气应注意防滑；夏季注意防晒补水，冬季注意湖面结冰区域的安全提示。

## 智能导览服务

系统依据游客对历史、自然、摄影和亲子体验的偏好推荐景点；进入景点触发半径后，可自动显示讲解内容。游客还可通过文字或语音询问景点历史、建筑特色、游览时长和拍摄建议。
