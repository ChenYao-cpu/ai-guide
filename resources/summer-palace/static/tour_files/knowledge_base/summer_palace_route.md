# 颐和园特色区域与路线知识

## 苏州街

苏州街位于后山后湖区域，沿水岸布置店铺式建筑，以江南水镇意象营造商业街景。它与前山开阔庄重的皇家园林景观形成对比，适合了解园林中的情景营造手法。

## 时间规划

- 60 分钟以内：选择仁寿殿、长廊等靠近东部入口的景点。
- 90 至 120 分钟：增加佛香阁或昆明湖湖岸游览。
- 150 分钟以上：可组合前山、湖区与后山苏州街，形成较完整的园林空间体验。

## 无障碍与亲子提示

湖岸和平缓区域更适合亲子与轻松游览。佛香阁所在区域台阶较多，应结合同行人员体力决定是否登高。带儿童游览时建议控制单个景点停留时长，并通过建筑彩画、桥梁结构和湖山视线等内容开展观察互动。
