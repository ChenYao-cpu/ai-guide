# 景点与数字人资源包

这是当前数据库公开展示资料的快照，包含多个城市景点，并非仅颐和园。

包含 48 个景点、3 条路线、2 条数字导游展示配置、4 份知识文档、10 条路线景点关联和 58 个资源文件。
不包含账号、登录密码、模型 API Key、微信密钥、星云应用绑定或游客记录。

新环境先配置自己的 .env 并启动后端初始化表，再在项目根目录运行：

```powershell
python scripts/import_resource_pack.py resources/summer-palace
```

导入工具保留已有同名记录，拒绝覆盖内容不同的资源。导游默认下架，需要绑定自己的星云应用。知识文档导入后为待处理状态，不表示已经建立知识索引。

资料核查与缺口见 docs/content-source-audit.md 和 data/scenic_content_audit.json。
图片在旧项目中的文件可用性已验证，原始图片出处和授权信息尚未核实；不要将“有本地图片”解释成“来源已核实”。
