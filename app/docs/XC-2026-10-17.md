# XC 分支：App 中英文切换与邮箱注册

日期：2026-10-17。App 版本：1.2.0。

## 可以直接用于汇报的内容

本轮仅提交 App 源码，以队长指定的 LZX `20525236a556f1b4a6bd70a8eaab65b65f378799` 为 Web 和接口参考，完成全 App 界面的中英文切换、邮箱验证码注册，以及英文景点搜索和路线规划衔接优化。注册支持输入校验、倒计时、限流提示和注册后自动登录。修复选择面板被底部导航遮挡、AI 预览时长与服务器结果不一致、推荐路线跳转丢失顺序及规划参数的问题。

验证包括 27 项自动化测试、全部注册页面与组件的文案扫描、5 条模拟接口浏览器流程，以及 HBuilderX 原生 App 资源编译。真实邮件收信和 Android 真机尚未验证，没有发布新的签名 APK。

## 分支与范围

- 交付分支：`XC`，基于固定提交 `2052523` 建立独立工作目录；不切换、不重置原工作目录。
- 在本轮核对时，远端 LZX 分支仍指向 `2052523`；未来 LZX 的更新不自动等同于本次固定基准。

- 基准提交未包含 `app/`；本次提交也包含此前本机已有的 App 基础代码、图片及模型，不将这些既有功能全部归为本轮新增。

## 功能明细

| 内容 | 实现 |
| --- | --- |
| 全局语言 | 登录页和“我的”切换，全部 10 个页面、8 个 Vue 组件共享响应式状态，本地保存并在重进页面时恢复 |
| 文案与布局 | 导航、表单、校验、空状态、弹窗、选择面板、加载进度、日期、已知景点名称和说明；英文长文案适配 |
| 邮箱注册 | 接入 LZX 现有验证码/注册/登录接口，密码确认、昵称/邮箱/验证码规则，发送冷却、限流和失败原因 |
| 注册恢复 | 注册成功后自动登录；登录失败保留已注册提示，可直接登录；切换模式保留账号并清理敏感输入 |
| 英文规划 | 识别常用英文时间、城市、兴趣和否定意图，适配现有中文关键词服务；用结构化结果展示英文路线 |
| 路线一致性 | 预览采用服务器总时长和步行数据；跳转保留规划预算、节奏、顺序及路线标识；防止重复创建导览 |
| 交互修复 | 时间/节奏/照片来源使用 App 内双语面板，修复导航遮挡，支持返回键和关闭操作 |
| 独立构建 | App 自有词典、坐标工具、依赖锁文件、测试及构建脚本，无需修改 Web 文件 |

## 演示步骤

1. 打开登录页，点击 English，检查整个注册表单、占位提示和按钮切换；切回中文。
2. 点击邮箱注册，演示密码不一致、验证码不满 6 位的提示，再发送验证码，检查倒计时禁止重复发送。
3. 在已配置 SMTP 的服务中，用自己的邮箱接收验证码并完成注册；若当前服务未配置，展示真实服务错误，不宣称已收信。
4. 进入“我的”切换 English，依次检查景点、AI 导游、收藏、排行、历史和导览界面；重启后语言仍保留。
5. 输入英文景点名搜索，如 `Longevity`；打开个性化时间和节奏面板，检查英文选项及取消按钮。
6. AI 导游选择 `2-hour family nature tour`，核对回复和路线预览采用同一服务器时长；点击使用路线，检查个性化规划内容保留。

## 仍依赖现有服务的事项

1. **真实收信**：服务器管理员需要配置 SMTP 发件账号及授权码。本轮未修改服务或私密配置，未验证真实邮件投递。
2. **动态内容语言**：用户内容和历史消息保持原文；测验、分析、图片识别说明等接口未提供英文结果时仍可能显示中文。完整动态内容双语需要另行授权后端支持。已支持语言参数的导览聊天按 App 当前语言请求。
3. **系统及第三方界面**：相机、相册、权限、地图和数字人 SDK 的系统提示由设备或 SDK 决定。App 自有选项和错误提示已统一语言。未使用可能导致 Android 重启的 `uni.setLocale`，见 [uni-app 国际化说明](https://uniapp.dcloud.net.cn/tutorial/i18n.html)。
4. **真机与安装包**：需要自己的地图 Key、可访问的服务器地址及签名配置后，在 Android 上进行地图、相机、语音、数字人和真实收信联调，再制作 APK。
