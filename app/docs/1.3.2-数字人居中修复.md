# App 1.3.2：数字人居中

保留 1.3.1 的安卓解码兼容、9ec7dec 基准、路线与用时、大地图及 LZX 景区图片，仅修改 App 导览数字人的布局。

- 取消数字人容器 `translateX(-10%)` 的固定左移。
- 约束 SDK 原生画布在容器内完整居中显示，避免 SDK 的缩放、对齐和偏移样式把画面挤出或裁切。使用原生画布的尺寸属性匹配，兼容 uni-app 对 `canvas` 标签选择器的编译转换。
- `avatar-layout-browser.cjs` 调用随包 SDK 的实际布局方法，使用模拟画布内容，覆盖 4 种屏幕尺寸和 3 种 SDK 对齐/偏移配置。修复前复现左偏约 31 像素，修复后验证源样式和 App 编译后的样式。

布局自动检查不等于真实数字人会话或 Android 真机验证。安装包版本为 1.3.2（132）。
