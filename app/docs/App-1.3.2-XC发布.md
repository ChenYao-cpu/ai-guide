# App 1.3.2 · XC 发布

## 代码范围

- 按用户指定的 main `9ec7decfa423e46fe05ebacff83cdd5d1cd9abe1` 作为 App 功能和界面的基准。
- 追加路线与用时、行程排序/移除、行前估算，以及途中按剩余时间、少走路、跳站或离园调整路线的预览与确认采用。
- 路线地图扩大为约半屏，完整框选路线；修复滚动时地图遮挡地点名及共用步道高亮被覆盖。
- 16 张景区照片原样取自 LZX `d3d35cd0f0bcbe41b7c091aee5723c3908fb8fae` 并随包发布。

XC 在发布前已合入 main。此次沿用 XC 现有历史，App 工作树以以上确认的基准与补丁为准；较旧 XC 的独立 AI 聊天补丁和偏好面板未迁入本版本。历史实现仍可在 Git 既有提交中查看。
