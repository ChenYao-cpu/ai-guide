# 固定服务站与管理员端

## 当前范围

Web 只保留固定服务站与管理员后台。

服务站入口为 `/station/:stationId`，默认 `/station/summer-palace-east`。`/`、`/station` 跳转默认站点。

管理员入口为 `/login`，后台由 `/admin` 进入。包括服务站、景点、知识库、数字人形象、路线资料、历史会话与分析、系统状态。

## 本次移除

- `/visitor/*` 原游客端与独立手机规划首页 `/m/home`。保留扫码接收与已领取行程所需的两个手机路由。
- 独立小程序源码、Capacitor 打包配置和专用依赖。
- 本机领取预览链接。二维码、share/claim 接口、领取页和后续行程交互恢复保留。
- `/station-preview/*` 独立屏幕预览页；管理页的打开链接直接进入服务站。
- 商品、订单、直播、旧数字主播管理页面及相关路由。
- 独立游客会话创建、收藏及小程序专用接口；已领取手机行程需要的问答、下一景点、定位、调整行程接口保留。
- 无剩余页面引用的游客组件、定位组合函数、Live2D 演示和专用测试。

## 保留的共享基础

数字人渲染、讲解合成、景区问答、地图、路网、路线优化和知识检索仍供服务站或管理员使用。历史会话数据模型仍供后台分析；没有清空用户数据库、历史记录、上传文件或模型权重。

游园须知里的官方信息二维码链接到景区官网，并非已移除的手机游客系统。

## 验证

2026-10-23：前端 68 项回归、后端服务站及路网/顺序 31 项回归通过，类型检查与生产构建通过。另以运行接口及浏览器核对保留入口、规划结果、旧入口不可用和管理员登录。

上一轮测试报告中的缺陷本轮不做专项修复。领取相关界面及代码作为范围裁剪被删除，不表示完成该功能的缺陷修复。

## 手机接收方案

服务站生成路线后点击“把这条路线带到手机”，显示二维码。手机领取后可看路线、与数字人问答、切换景点及调整行程；大屏结束接待不清除手机行程。扫码凭证只置于 fragment，不缓存接待和领取接口。二维码弹窗不提供“在本机预览领取页”链接。手机端结束后返回服务站入口，不恢复独立手机首页或小程序。

开发前端需监听局域网地址（如 `--host 0.0.0.0`），手机与电脑同网。正式部署优先使用统一 HTTPS 域名。

本次恢复手机接收流程的验证：69 项保留端前端测试、30 项手机交互/行程调整测试、16 项服务站后端测试通过；类型检查和生产构建通过。浏览器验证领取同一方案、手机问答与下一站切换成功，大屏闲置复位后仍可领取和继续行程。局域网二维码地址由本机 HTTP 检查返回 200；未使用真实手机硬件验收。
