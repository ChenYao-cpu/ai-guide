# 服务站缺陷修复记录

日期：2026-10-23

依据：桌面《服务站测试报告.md》中的 ST-01 至 ST-09。原报告保持不变。

分支：`codex/web-station-latest-20261022`，源码版本及提交记录以该分支的 Git 历史为准。

## 逐项结果

1. **ST-01 切换景点串资料：已修复。** 本轮问题明确提及景点时优先使用该景点；没有明确景点的追问才继承旧主题。中英文回归均覆盖新主题、配图及隐含追问；实际页面先问十七孔桥再输入长廊，答案、主题标签和配图均切换为长廊。
2. **ST-02 否定指令误改路线：已修复。** 按语句识别否定的路线修改，过滤“不要改为北宫门”等指令，同时保留“不想去某景点”的明确排除意图。测试覆盖中英文否定、否定缩短、否定移除、混合肯定/否定语句及正常修改。自然语言解析仍是保守规则，不能视为已覆盖所有任意表述。
3. **ST-03 切换语言导致路线失效：已修复。** 路线有效性只依赖时间、终点、台阶限制和景点选择；语言切换清理旧语言提示。领取快照使用当前语言，不修改原路线。浏览器验证中文生成的 6 站、73 分钟、1.22 km 路线切换英文后无需重算即可领取。
4. **ST-04 取消后问题与答案错配：已修复。** 回答成功后再同时更新问题与答案；取消时保留上一组完整问答并恢复输入框内容。可控延迟回归验证迟到响应不会覆盖已取消的状态。
5. **ST-05 旧语言迟到回答回填：已修复。** 切换语言会取消当前请求并更新请求版本；旧响应不会写入新语言页面。回归验证请求被取消、旧答案不出现且输入恢复可用。
6. **ST-06 英文介绍本地兜底失配：已修复。** 从已有公开英文资料生成按景点名称关联的独立内容索引；中文简介修改后仍能获取英文基础介绍。覆盖全部 16 个景点，未新增机器编造的景点事实。
7. **ST-07 小数分钟显示服务故障：已修复。** 前端要求 20—480 范围内的整数，显示具体提示并禁止无效提交；服务站后端参数错误返回结构化 422，前端兼容参数错误列表。实际服务验证小数分钟、空问题和超长问题均返回对应输入提示。
8. **ST-08 不连通误报时间不足：已修复。** 搜索路线前检查候选景点能否同时连接服务站与出口。北宫门避台阶组合现在提示当前路网未找到满足条件的完整路线；真正时间不足的情况保留预算提示。自动测试与实际接口均验证。
9. **ST-09 滚动阅读误触发闲置复位：已修复。** 滚轮、触摸移动及嵌套区域滚动均刷新活动时间，组件卸载时清理监听。三种交互分别以可控时间测试持续阅读超过闲置时限，以及停止操作后的正常复位。

## 验证结果

- 前端：13 个测试文件，**106 项通过**，包含服务站及保留的手机交互等共享能力；本次新增 7 项服务站交互回归。
- 后端与共享路线：**45 项通过**，其中服务站 21 项；本次新增 5 项服务站回归。数据库单元测试使用独立 SQLite。
- 类型检查及生产构建通过。仍有既有的大包体积及 Sass 弃用提示，不等同于功能故障。
- 实际运行服务的 9 项针对性接口检查通过：输入错误、路径不连通、正常规划、否定修改、新景点主题、英文分享及领取预览。
- 浏览器验证：整数分钟提示、语言切换后保留路线、生成二维码、英文领取页、领取成功反馈、大屏结束后领取行程刷新仍有效、继续下一站、连续景点问答。测试行程已正常结束。
- 手机领取验证采用本机独立浏览器页，并非手机流量网络实测。手机与电脑不在同一网络的问题仍需可达的公网 HTTPS 入口；本次未开放公网服务。
- 现场硬件、真实麦克风与扬声器、跨浏览器和长期压力运行不在本次修复验收范围。
