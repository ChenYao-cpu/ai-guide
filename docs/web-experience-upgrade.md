# 网页端讲解、图文、路线与维护升级

2026-10-16；在 LZX 工作区实施。范围为 Vue 网页（含 `/m/home`、`/m/tour/:id` 这两个浏览器入口）和共享后端；未改原生微信小程序或 App 页面。

## 讲解内容

- 标准讲解对介绍、历史、建筑、看点问题按 2–3 段、约 220–420 字组织；深入模式资料充足时约 450–800 字。英文策略相应扩展；这些是生成目标，不是每个问题强制凑足字数。
- 长度、年代、设施、下一站等具体问题继续直接回答。“一句话说重点”仍可缩短；继续追问补充新内容，资料有限时不重复原文凑篇幅。
- 本地备用讲解也扩充了背景、空间观察和易混淆事项。管理员修改的简介、历史详情、拍照建议和游览提醒进入对应备用回答。
- 事实核对现在能引用生成时实际提供的公开景点数据库字段快照；每个片段含稳定 ID、字段名和内容版本。避免模型依据数据库展开后，却因审核只看简短备用答案而被错误退回。资料仍作为数据处理；没有来源的事实不补写。
- 中文播报保留最多 10 句 / 800 字，英文最多 10 句 / 240 词；深入文字可比口述更长。打断功能保留；未恢复已移除的慢速、独立重播功能。

## 图文联动

回答内新增可折叠“看图与时间线”；最新回答默认展开，旧回答收起。图片可打开原图、缩放查看局部；官方来源保留。附件按本轮所讲景点和主题选择，跨景点问答不会移动实际游览位置。

首批原站参考图片覆盖长廊、昆明湖、十七孔桥、南湖岛、铜牛、石舫六处。图片 URL、来源页保存在 `data/tour_visual_catalog.json`；不复制第三方图片文件，不把生成示意图当作实景。后台已有景点图片优先使用，其他景点配置图片后也能自动显示。图片加载失败显示可理解的状态并保留原文链接。

长廊及十七孔桥有来源可核对的年代卡，只在回答确实涉及对应年份时显示；其他景点不编造时间线。历史角色已有的史料时间线也可展示。这里按问答轮次关联图文，未声称已实现语音逐词或视频逐帧同步。

## 路线显示及一致性

- 浏览路线：已选标记使用实际游览顺序编号，地图叠加紫色虚线；展开可查看每一段步行距离、步行时间和停留时间。个性化页可按需展开同一套路线地图。
- 导览页顶部“查看路线”打开地图和逐段清单，当前站突出显示。保持左侧数字人完整展示，不挤占一屏布局。
- 路线卡片、地图、开始导览和进入时介绍统一使用停留＋步行＋休息口径。个性化总预算另外计入用户配置的出发、离园和排队预留，详细组成继续展示。
- 调整行程展示原／新路线、时间差、步行差和移除原因；仅确认后写入，保留已完成前缀及当前站，旧签名重复提交被拒绝。当前站停留不再重复计入“从离开当前站起”的比较。
- 修复自动选城市递归遗漏离园方向、排队预留、跳过景点参数的问题；对应预算和避让回归已通过。

距离来自已有 OSM 园内路网快照。虚线只是顺序示意，不是沿道路绘制的导航路径；部分非目录景点仍按直线系数估算，界面标识依据。未接入实时封路、客流、排队或船渡信息，也不声称轮椅全程可达。无坐标时显示未知，不伪造零距离。

## 稳定性

- 数字人配置、能力查询、地图资源、会话信息和切换站点均有等待上限；模型导览请求增加整体截止时间，SDK 内部重试不能无限延长界面等待。
- 数字人异常后最多自动重连两次（间隔 2 秒、6 秒），失败仍有手动入口。主动断开后不会自动连回；旧实例事件不会重新激活已销毁的画布。完整初始化保留 90 秒上限，避免资源仍在正常加载时过早销毁。
- 加载只显示文字；初始化成功后才显示画布。云服务失败时文本问答仍可用，不把云服务可用性当作本地代码能永久保证的事情。
- 会话加载、问答和媒体请求隔离过期响应；切换会话或离开页面取消请求。断网恢复时可重新获取会话；失败问题保留在输入框并显示错误。
- 同一浏览器标签刷新后恢复服务器会话、当前站和对话，保留未发送输入与讲解方式；首页提供“继续导览”。凭证和恢复入口按标签会话保存，不向陌生新浏览器承诺自动恢复。结束后清理入口；已结束会话不能继续问答。

## 后台维护预览

景点编辑、路线编辑、数字人编辑及知识库管理提供“游客效果预览”。统一的只读抽屉支持选择景点／数字人、查看当前草稿介绍、讲解示例、相关图片、已保存关联路线及当前公开索引命中原文。路线编辑还可预览未保存顺序的地图和时间。数字人编辑可查看未保存的公开角色配置；不传平台密钥，也不为预览创建云端数字人会话。

草稿仅在内存叠加；不调用保存接口、不创建游客导览。待审核知识不会混入公开检索结果；保存景点与审核发布知识文档仍是独立操作。英文预览使用同一翻译入口，原文证据保留原文。景点编辑补齐拍照建议、游览提醒、服务设施、停留时间、城市及 WGS84 坐标。

## 检查与实测

根目录运行 `python -m unittest discover -s scripts/tests`；前端运行 `node node_modules/vitest/vitest.mjs run --maxWorkers=1 --minWorkers=1`、`vue-tsc --build --force`、`vite build`。

真实接口验收保存在忽略目录 `work_dirs/web-experience-acceptance.json`：长廊普通历史 292 字、具体长度 43 字、英文历史 598 字符；三站路线步行 2086 米、含停留休息 118 分钟。调整示例从剩余 91 分钟降为 51 分钟，预览未写入，确认保持进度，重放返回 409。验收会话已结束，未改游客已有路线或内容。这些是可复现功能样本，不是问答准确率或现场到达时间保证。

最终结果：110 项 Python 测试、104 项前端测试通过，全项目类型检查和生产构建通过。构建保留既有 Sass 弃用和大包体提示。浏览器实测包含完整数字人连接和播报、中文／英文参考图片及时间线、原图放大、路线详情、调整前后地图，以及后台未保存草稿预览。公开接口复查确认后台预览未改变已发布简介。截图保存在 `work_dirs/web-guide-visual-upgrade.png`、`work_dirs/web-route-comparison.png`；浏览器验收会话 178 和接口验收会话 179 均已结束。
